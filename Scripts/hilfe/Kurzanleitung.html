TunnelTerminal – Kurzanleitung

TunnelTerminal verwaltet PuTTY-Sitzungen auf dem Mac. Verbunden wird mit PuTTYs eigenem plink, das in der App steckt; Protokoll, Verschlüsselung und die Prüfung der Hostschlüssel bleiben bei PuTTY.

1. Verbinden

  • Schnellverbindung: oben in der Seitenleiste benutzer@server:port eingeben, Verbindungsart wählen (SSH, Telnet, Raw) und Return drücken. ⇧⌘K setzt den Cursor in das Feld. Beispiel: test@server.example:2222
  • Sitzungen speichern: Ablage › Neue Sitzung (⇧⌘N). Gruppen entstehen über den Namen: „Büro/Webserver“. Doppelklick auf eine Sitzung verbindet.
  • Aus PuTTY übernehmen: Ablage › Importieren – einen PuTTY-Ordner (Mac, Linux) oder eine Registrierungsdatei (.reg) aus Windows-PuTTY. Vor dem Import zeigt die App eine Liste mit Warnungen.
  • Jede Verbindung läuft in einem Tab (⌘T). Ist der Tab schon verbunden, öffnet sich die nächste Sitzung daneben.
  • Geräte im eigenen Netzwerk: Beim ersten Verbinden zu einer Adresse im lokalen Netzwerk (z. B. ein Router oder ein Server zu Hause) fragt macOS, ob TunnelTerminal darauf zugreifen darf. Erlaube es und verbinde erneut (⌘R). Ändern lässt sich das unter Systemeinstellungen › Datenschutz & Sicherheit › Lokales Netzwerk.

2. Die erste Verbindung zu einem Server

Beim ersten Verbinden zeigt plink den Fingerabdruck des Servers und fragt, ob es ihn sich merken soll. Vergleiche ihn vorher mit dem Fingerabdruck, den der Server selbst nennt. Danach fragt plink nur noch, wenn sich der Schlüssel ändert. Steht im Terminal „Press Return to begin session“, genügt Return. Bekannte Hostschlüssel stehen unter Fenster › Bekannte Hostschlüssel.

3. Anmelden

  • Mit Schlüssel (empfohlen): Fenster › Schlüssel erzeugt einen Ed25519-Schlüssel und zeigt die Zeile, die auf dem Server in ~/.ssh/authorized_keys gehört. Im Sitzungs-Editor unter „Anmeldung“ die Schlüsseldatei wählen.
  • Mit dem Agenten von macOS: ssh-add --apple-use-keychain ~/.ssh/id_ed25519 im Terminal; plink nutzt den Agenten von selbst.
  • Mit Passwort: plink fragt im Terminal. Auf Wunsch sichert der Sitzungs-Editor das Passwort im Schlüsselbund dieses Macs; es gilt nur für den Benutzer, Server und Port, für die es gesichert wurde.

4. Im Terminal

  • Suchen (⌘F), Bildschirm und Verlauf leeren (⌘K), Alles kopieren (Bearbeiten-Menü), Verbindung duplizieren (⌘D), Titel ändern (Fenster-Menü), Trennen (⌘.), Erneut verbinden (⌘R).
  • Text mit Zeilenumbruch fügt die App erst nach einer Rückfrage ein (⌘↩ fügt ein, ⎋ bricht ab).
  • Schrift, Farben und Rückblättern stehen in Profilen (Einstellungen › Profile); das Profil eines Tabs wählst du im Inspektor rechts (⌥⌘I).
  • Ein Sitzungsprotokoll lässt sich je Sitzung im Editor einschalten; es liegt unter ~/Library/Logs/TunnelTerminal.

5. Tunnel, Proxy, Seriell

Port-Weiterleitungen (lokal, entfernt, dynamisch als SOCKS-Proxy), Proxys und Sprungserver stellst du im Sitzungs-Editor ein; der Knopf „Tunnel“ in der Symbolleiste öffnet ihn direkt dort. Weiterleitungen stehen bereit, sobald die Sitzung läuft (nach „Press Return to begin session“). Serielle Geräte (/dev/cu.*) sind eine eigene Verbindungsart im Editor.

6. Dateien übertragen

Während einer SSH-Verbindung: Dateien aufs Terminal oder auf die Fläche im Inspektor ziehen, oder den Knopf „Hochladen“ benutzen. Den Zielordner auf dem Server gibst du danach ein (leer = persönlicher Ordner). Verbindung › Datei herunterladen lädt eine Datei vom Server. Gibt es die Datei schon, fragt die App vorher.

7. Links aus anderen Apps

Links wie ssh://test@server.example:22 oder telnet://192.0.2.10 öffnet TunnelTerminal, wenn es unter Einstellungen › Erweitert als Standard-App festgelegt ist. Vor jedem Verbinden fragt die App mit der vollständigen Adresse nach; achte auf die Zeile „Server“. Übernommen werden nur Benutzer, Server und Port; Links mit Passwort oder weiteren Angaben öffnet sie nicht. Telnet ist unverschlüsselt, bei SSH probiert plink die Schlüssel aus deinem Agenten.

8. Sicherheit auf einen Blick

  • Hostschlüssel werden nie ohne deine Bestätigung angenommen.
  • Passwörter liegen nur im Schlüsselbund dieses Macs und gehen über eine Pipe an plink, nie als Argument oder Datei.
  • Programme auf dem Server dürfen die Zwischenablage nur nach Rückfrage füllen und nie lesen; Links aus dem Terminal öffnen sich nur nach Rückfrage (strenger einstellbar unter Einstellungen › Sicherheit).
  • Sitzungen, die beim Verbinden etwas auf diesem Mac ausführen würden (lokaler Proxy-Befehl), verbinden erst nach einer Warnung.
  • Die App hat kein Konto und schickt nichts ins Internet außer deinen Verbindungen.

9. PuTTY-Updates

Welche PuTTY-Version eingebaut ist, zeigt Hilfe › PuTTY-Version. Neue Versionen und Sicherheitshinweise veröffentlicht das PuTTY-Projekt auf seiner Website (Knopf unter Einstellungen › Erweitert). Bringt PuTTY ein Sicherheitsupdate, braucht es eine neue Version von TunnelTerminal – die eingebauten Werkzeuge lassen sich nicht einzeln austauschen.

10. Tastenkürzel

Alle Kürzel stehen unter Hilfe › Tastenkürzel.
